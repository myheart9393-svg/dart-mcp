# /dart-event $ARGUMENTS

`$ARGUMENTS`는 접수번호(rcept_no, 14자리)다. 수시공시 한 건을 읽고 **3단 요약 보고서**를 작성한다.
CLAUDE.md 공통 원칙을 따른다.

## (a) 읽기 순서

1. `get_disclosure_outline(rcept_no)` → 파일 목록과 섹션. 수시공시는 보통 1만 자 이내이므로
   total_chars가 30,000 이하면 `get_disclosure_section(rcept_no, "0")`부터 모든 섹션을 순서대로 읽는다
   (section 0에는 회사명·제출일이 있다). 30,000자를 넘으면 목차에서 결정 내용이 담긴 섹션만 고른다.
2. 공시 본문에서 회사명을 확인하고 `find_company(회사명)`으로 corp_code를 얻는다.
3. `search_disclosures(corp_code, <접수일-1년>, <접수일>, pblntf_ty="B", max_results=50)`로 직전 1년의
   주요사항보고를 받아, report_nm이 같은 종류(예: "자기주식취득결정")인 공시를 찾는다.
   - 있으면 가장 가까운 1건의 `get_disclosure_outline` → 결정 섹션만 읽어 규모를 비교한다.
   - 없으면 "직전 1년 내 유사 공시 없음"으로 적는다.
4. **짝 공시·연계 공시** (합병·분할합병·주식교환·영업양수도·자산양수도·공개매수 관련일 때):
   - 본문의 거래 상대방(합병상대회사·교환 상대회사·양수인/양도인)을 `find_company`로 찾고, 상대가 상장사면
     `search_disclosures(<상대 corp_code>, <접수일>, <접수일>, pblntf_ty="B")`로 **같은 날 짝 주요사항보고서**를 찾는다
     (없으면 ±3일로 넓힌다). 있으면 결정 섹션만 읽어 비율·가액·일정이 서로 맞는지 1줄로 적는다.
   - `search_disclosures(corp_code, <접수일-30일>, <접수일+30일>, pblntf_ty="D")`에서 report_nm에 "공개매수"가 든 공시
     (공개매수신고서·공개매수결과보고서, 상대 회사 corp_code로도 한 번)를 찾는다. 있으면 공개매수 가격·기간·목적이
     이번 결정(주식교환·합병·상장폐지 계획 등)과 어떻게 이어지는지 3단 요약의 "주주 영향"에 적는다. 없으면 "연계 공개매수 없음".
   - 가치평가가 있는 거래면 `search_valuation_disclosures(<접수일>, <접수일>, corp_code=…)`의 related_rcept_nos(짝 증권신고서)를 함께 적는다.
5. 공시 종류가 자기주식·배당·증자처럼 주식 수와 연관되면, 본문 표의 "발행주식총수" 또는 "비율(%)" 항목을
   근거로 지분 영향을 계산한다 (원문에 비율이 있으면 그것을 우선 쓰고 계산값은 "계산" 표기).

## (b) 보고서 고정 목차

파일: `reports/<회사명>_수시공시_<YYYY-MM-DD>.md`(오늘 날짜, 공통 규칙 `<회사명>_<종류>_<날짜>`). 같은 날 같은 회사의 수시공시 보고서가 이미 있으면 `reports/<회사명>_수시공시_<YYYY-MM-DD>_<rcept_no>.md`. 보고서 머리에 rcept_no를 적는다.

```
# <회사명> <공시 제목> (rcept_no <rcept_no>, 접수일 <rcept_dt>)

## 1. 한 줄 요약
(무엇을, 얼마나, 왜 결정했는가 한 문장)

## 2. 핵심 요약
(5줄 이내: 결정 내용 / 규모(금액·주식 수·비율) / 기간·방법 / 목적 / 이사회 결의 정보)

## 3. 상세
### 3.1 결정 내용
### 3.2 규모와 조건
(표: 원문 표의 핵심 행만 발췌)
### 3.3 주주 영향
(지분율 변화·유통주식 변화·배당 영향 등. 계산값은 "계산", 해석은 "추정:")
### 3.4 직전 유사 공시와 비교
(표: rcept_no, 접수일, 보고서명, 규모 — 없으면 "없음")
### 3.5 기타 참고사항
(원문 "기타 투자판단에 참고할 사항"을 요약)

## 부록. 참조한 공시·섹션 목록
| rcept_no | file_id | section_id | 제목 | 글자 수 |
```

## (c) 인용 규칙

- 모든 수치와 날짜에 `(rcept_no, section_id)` 출처를 붙인다. 비교 대상 공시는 그 공시의 rcept_no로 표기한다.
- 원문 표를 통째로 옮기지 않는다. 핵심 행만 발췌한다.
- 원문에 없는 영향 분석은 "추정:" 으로 시작한다. 계산은 "계산" 표기.
- 같은 섹션은 한 번만 읽는다. 끝나면 보고서 본문, 툴 호출 횟수, 읽은 총 글자 수를 채팅에 보고한다.
